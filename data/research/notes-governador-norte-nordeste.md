- **CE — Ceará**: resolvido. Quaest (31/08-03/09, publ. 04/09, CE-01149/2026): Ciro Gomes 45% x Elmano de Freitas 34%. AtlasIntel (28/08-02/09, publ. ~04/09, CE-02357/2026 — registro diferente do já listado no arquivo principal): Ciro 48,4% x Elmano 45,8%. Há também Datafolha (31/08-02/09, CE-04122/2026) com Ciro 46% x Elmano 37%, não incluída entre as 2 mais recentes por ter dataFim igual à do Atlas mas publicação um dia antes — vale considerar substituí-la pela AtlasIntel na consolidação final se o critério de "mais recente" priorizar dataFim em vez de publicação.
- **PB — Paraíba**: resolvido. Instituto Anova (03-05/09, publ. 08/09, PB-01471/2026, também BR-02714/2026): Lucas Ribeiro 43,4% x Cícero Lucena 18,2% x Efraim Filho 12,1%. AtlasIntel (28/08-02/09, publ. ~03/09, PB-01118/2026 — mesmo registro já citado no arquivo principal sem percentuais): Lucas Ribeiro 42,4% x Efraim Filho 30,9% x Cícero Lucena 19,8%. Havia também uma pesquisa Instituto IPOPP (Lucas Ribeiro 32,35%, Cícero 24,40%, Efraim 12,50%) e Real Time Big Data de maio (PB-03748/2026), ambas mais antigas — não usadas.
- **RR — Roraima**: resolvido. AtlasIntel (04-09/09, publ. 11/09, RR-07280/2026 — mesmo registro já citado): Arthur Henrique 60,7% x Soldado Sampaio 32,4%. Quaest (23-26/08, publ. 27/08, RR-04765/2026 — mesmo registro já citado): Arthur Henrique 60% x Soldado Sampaio 27%. A pesquisa Real Time Big Data (RR-03170/2026, mesmo período do Atlas) permanece sem percentuais localizados.
- **BA — Bahia**: resolvido. Real Time Big Data (04-08/09, publ. 09/09, BA-01568/2026 — mesmo registro já citado): Jerônimo Rodrigues 45% x ACM Neto 44% (empate técnico). Paraná Pesquisas (23-25/08, BA-07628/2026 — mesmo registro já citado, contratante S2R Comunicação/Bahia Notícias): ACM Neto 48,6% x Jerônimo Rodrigues 40,1%; data exata de publicação não confirmada (fontes secundárias entre 27 e 29/08).

Os registros no novo JSON usam os mesmos números de registro TSE já presentes em `polls-governador-norte-nordeste.json` sempre que a pesquisa identificada foi a mesma — ou seja, este arquivo complementa (não duplica de forma independente) as lacunas daquele arquivo.
